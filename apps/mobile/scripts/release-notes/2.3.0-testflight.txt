Kaata 2.3.0 testing build 45

Update in place without uninstalling or clearing data. Use disposable records for shared-account and recovery checks. These are checks to perform, not claims of completed phone testing.

- Home balance cards: tap To collect or To pay to expand that side and filter the customer list. Tap the selected card again to show both sides. Swipe the customer list left for pay or right for collect; swiping the cards still changes currency. Existing search, group, currency and sort choices should remain. Manual interaction stops automatic currency movement.
- Search and filters: opening sort/filters dismisses the search keyboard and keeps the popup open. Dismissing a lingering keyboard should not close the filters. Check popup placement, keyboard timing and reopening on both phones.
- Settled tallies: settled history belongs below active tallies behind See settled tallies. Expand/collapse it, search old records and open a reminder into history. Merely reaching a zero balance must not archive an unsettled period. Check independent currencies and pending tallies.
- Shared links: new invitations offer Require approval, Notifications only (both people can add) and Only I can add (link creator adds; recipient views and receives alerts). Both phones need this update for the new creator-only mode. Check recipient add/edit/settle restrictions, offline/retry, multiple currencies and unlinking. Existing links keep their mode, approval rules and balances.
- Currency labels: customer/tally rows, currency choices and shared bills should show a single currency code or symbol, without redundant pairs such as AUD A$. Check each currency's independent balances and per-contact default.
- Add/Edit and calculator: check Amount/Note handoff, scrolling, Date beneath Show more, safe saved-currency corrections, unfinished calculations, decimals, percentages and memory. Editing and offline retry must preserve existing records.
- Ratings: no prompt on the first tally. Eligibility needs seven active tally days across at least a full week and ten successful new tallies, followed by an idle Home screen. Interaction, keyboard, popup or navigation cancels it. Apple's native rating card is disabled in TestFlight, so its absence here is expected.
- Code emails: sign-up, password reset and password setup show a selectable code box with copy instructions in English, Dari and Pashto. Check leading zeros and long-press copying; built-in one-tap copy depends on the email app.
- Regression: check role-disabled controls, search above the Android keyboard, English/Dari/Pashto layouts, bills and balance-only WhatsApp reminders, PDF/CSV export, sign-in, backup/restore, reminder cold-start navigation and canceling an unused link without changing original tallies.

Known testing issue: Android notification-only alerts can retain an amber pending-clock icon even though the tally is recorded. Notification text, balances and approval-action guards remain correct.

Testing only: existing Team (Expo) internal TestFlight group. No App Store review, public release or external beta distribution.
