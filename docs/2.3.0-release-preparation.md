## Included work

- Pending mobile, backend and web work checkpointed in `954741c`: separate
  per-currency balances and immutable tally currencies; enabled currencies per
  kaata; unified Home, balance carousels, search/filter and selection refinements;
  sheet, keyboard, date and note improvements; reminder deep links; complete
  multi-currency bills and Persian sharing artwork with «برای همیشه رایگان».
- `codex/all-country-phone-codes` merged in `f7e019c`: all 245 supported geographic
  dialing regions, localized offline names and search, numbering-plan-aware
  normalization, and full-number contacts matching.
- `codex/all-currencies` merged in `3d028df`: 155 monetary currencies with
  searchable localized names, codes, symbols and country aliases. Existing
  multi-currency behavior was preserved instead of restoring the branch's older
  global currency model. Onboarding retains one currency; later new-kaata forms
  and settings support the saved enabled set. The existing 64-enabled-currency
  limit is enforced before selection, including when changing a new kaata's
  default. Tally pickers show enabled currencies only. Precision guidance
  explains the existing two-decimal money limit.
- `codex/android-startup-followup` merged in `bd4fe83`: pending Android key setup,
  signing and public-signature verification improvements. Current currency-scoped
  credit caching and no-op notification suppression remain intact. Missing or
  inconclusive native verification retains the established JavaScript verifier.
- `codex/shared-account-safety` reconciled in `f99e621`: implementation was already
  included; the remaining documentation now reflects local integration and the
  coordinated rollout requirement.

The other release/refinement, Android performance, colored action and production
fix branches inspected were already ancestors of `main`. The parked July
`feat/revive-nearby-sync` experiment stays separate. Existing stashes are retained:
superseded safety snapshots, the already committed calculator, an unfinished
referral prototype and the obsolete BLE plugin are not reapplied.
